# Настройка CRM AI Desk → amoCRM (аналитика, без Med24)

Отдельная **внешняя/приватная интеграция** только для Desk. Ключи Med24 не используем.

## 1. Создать интеграцию в amoCRM

Нужны права **администратора** аккаунта `kuhhospital`.

1. Откройте https://kuhhospital.amocrm.ru
2. Слева: **amoМаркет**
3. Справа вверху **⋯** (три точки) → **Создать интеграцию**
4. Выберите **Внешняя интеграция** → **Создать**  
   (так не отключается техподдержка amo; для long-lived токена этого достаточно)
5. Заполните:
   - **Название:** `CRM AI Desk Analytics` (или `KUH Analytics`)
   - **Описание:** `Аналитика звонков, STT и заметки AI в сделки`
   - **Ссылка для перенаправления:** `https://example.com` (можно так — для long-lived токена OAuth-редирект не нужен)
   - **Предоставить доступ:** максимально широко / **Все** (нужны сделки, контакты, события, примечания, пользователи, файлы)
6. Сохраните интеграцию

## 2. Ключи и долгосрочный токен

1. Откройте созданную интеграцию → вкладка **Ключи и доступы**
2. Скопируйте:
   - **ID интеграции** → это `AMO_CLIENT_ID` / Client ID
   - **Секретный ключ** → `AMO_CLIENT_SECRET` (если показывается)
3. В блоке **Долгосрочный токен** нажмите **Сгенерировать токен**
4. Срок: лучше **максимум (до 5 лет)**
5. **Сразу скопируйте токен** — повторно его не покажут

## 3. Прописать в CRM AI Desk

### Вариант A — в приложении (удобнее)

1. Откройте **CRM AI Desk** → раздел **CRM**
2. Провайдер: **amoCRM**
3. Заполните:
   - Название: `KUH Analytics`
   - Поддомен: `kuhhospital`
   - Long-lived token: вставьте токен
   - Client ID / Secret: из вкладки «Ключи и доступы»
4. **Проверить** → должно быть `OK · …`
5. **Сохранить** — профиль станет активным

### Вариант B — прислать мне ключи

Пришлите в чат (или вставьте сами в `.env`):

```
AMO_SUBDOMAIN=kuhhospital
AMO_CLIENT_ID=...
AMO_CLIENT_SECRET=...
AMO_LONG_LIVED_TOKEN=...
```

Я обновлю профиль Desk и перезапущу API/worker.

## 4. Что должно заработать после подключения

- Сбор сделок / звонков / чатов из amo
- STT + анализ
- Запись AI-заметок в карточки сделок (`WRITE_AMO_CALL_NOTES=1`)

## 5. Старая Med24-интеграция

- Токены `MED24_*` из Desk удалены
- Старый Client ID Med24 (`3ccbcd8e-…`) больше не используем для аналитики
- Интеграцию Med24 в amo можно оставить для самого Med24 — Desk к ней не ходит
