# Chrome-расширение KUH AI (RU/UZ)

Чистая установка **только в Google Chrome**.  
Яндекс / CDP / убийство процессов — **не используем**.

## 1. Backend (должен быть online)

```
C:\Users\ACC-2\amocrm-analytics\start_always_online.bat
```

Проверка: http://127.0.0.1:8090/health

## 2. Установить расширение

1. Открой Chrome  
2. Вставь в адресную строку: `chrome://extensions`  
3. Включи **Режим разработчика** (справа сверху)  
4. **Загрузить распакованное расширение**  
5. Выбери папку:

```
C:\Users\ACC-2\amocrm-analytics\browser-extension
```

## 3. Как пользоваться

1. https://kuhhospital.amocrm.ru → любая **сделка**  
2. Справа внизу синяя кнопка **KUH AI** (свёрнуто — **не мешает**)  
3. Нажми → панель развернётся  
4. **Анализ / Tahlil** — разбор RU+UZ  
5. **−** или кнопка снова — свернуть  

В CRM **ничего не пишет**.

## 4. Обновление

После правок кода: `chrome://extensions` → ↻ Reload у KUH AI.
