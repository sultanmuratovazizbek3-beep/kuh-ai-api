UZ → RU: куда писать данные ИП в форме amo
------------------------------------------
Форма amo ориентирована на РФ-паспорт. Для Узбекистана ИП заполняйте так
(только своими реальными данными — не выдумывать):

| Поле в форме amo (RU)              | Что вписать (УЗ ИП)                          |
|------------------------------------|----------------------------------------------|
| ФИО / Enter your full name         | ФИО как в паспорте УЗ (кириллица)            |
| Серия паспорта (Passport Series)   | Серия УЗ паспорта (напр. AA / AB).           |
|                                    | Плейсхолдер «00 00» — РФ-формат; если        |
|                                    | валидатор ругается, попробуйте «AA» или      |
|                                    | «A A» / первые символы серии                 |
| Номер паспорта (Passport number)   | Номер УЗ паспорта (цифры)                    |
| Дата выдачи (Date of issue)        | Дата выдачи паспорта, формат ДД.ММ.ГГГГ      |
| Кем выдан (Issued by)              | Орган выдачи УЗ (как в паспорте)             |
| Адрес регистрации                  | Адрес регистрации / проживания в УЗ          |
| ИНН (TIN, до 12 цифр)              | СТИР / ИНН ИП Узбекистана (только цифры).    |
|                                    | Если 9 цифр — вписать как есть; ПИНФЛ 14     |
|                                    | цифр в это поле не влезает — используйте     |
|                                    | СТИР ИП                                      |
| Телефон                            | +998… (можно оставить код +998)              |
| E-mail                             | рабочий email ИП / клиники                   |

Не подставляйте чужие/фейковые паспортные данные — amo может отклонить
(Invalid data) или создать юридические риски.


После сохранения соглашения
---------------------------
Скрипт сам:
  1) загрузит public\kuh-assistant-widget.zip в интеграцию
  2) проверит has_widget=true
  3) выставит access_mode=all_managers
  4) пропишет api_base из public\API_PUBLIC_URL.txt

Текущий api_base для настроек виджета:
  см. файл public\API_PUBLIC_URL.txt
  (на момент подготовки: https://hanging-persons-approach-worm.trycloudflare.com)

Если туннель перезапускали — обновите api_base в настройках виджета
на новый URL из этого файла.


Параллельный рабочий путь (уже сейчас)
--------------------------------------
Edge-расширение browser-extension → панель «KUH AI» в сделке.
API локально: http://127.0.0.1:8090/health


Команды
-------
Проверить соглашение:  .\.venv\Scripts\python.exe wait_and_upload_widget.py --status
Один раз (если уже performed):  .\.venv\Scripts\python.exe wait_and_upload_widget.py --once
Ждать и залить:       .\.venv\Scripts\python.exe wait_and_upload_widget.py
Или:                   УСТАНОВИТЬ_ВИДЖЕТ.bat

Если скрипт пишет COOKIE_ERROR / 401:
  войдите в kuhhospital.amocrm.ru в Yandex или Edge,
  закройте браузер на ~5 секунд (чтобы отпустить Cookies DB),
  снова запустите скрипт.
